SIMULATION DE PLANCHE À VOILE

WIND RIDER '86

FORCE DU VENT
Téléphone à l'horizontale. Moitié gauche de l'écran = bras gauche, moitié droite = bras droit.
Pouce vers le haut : tu tends le bras. Vers le bas : tu le ramènes. Gauche / droite : tu déplaces la voile de ce côté (vers l'avant ou l'arrière de la planche).
Écarte la main arrière pour ouvrir la voile, ramène-la pour border (plus de puissance). Ramener les deux mains = voile bordée et mât au vent.
Voile vers l'avant = tu abats (tu t'éloignes du vent). Vers l'arrière = tu lofes (tu remontes au vent).
Lâche un pouce = le pratiquant lâche la voile de ce côté. Tout lâché = la voile tombe. Repose un pouce = il la remonte tout seul.
Passe l'axe du vent : virement / empannage automatique, les rôles avant/arrière s'inversent, petit temps mort pour reprendre la voile.
Penche le téléphone gauche/droite (comme un volant) pour carver quand tu planes. Lève le téléphone d'un coup pour sauter.
Les traînées blanches montrent le vent. Houle dans le dos = accélération, houle de face = décollage.
